# Spire VPN для Android

Приложение Spire VPN для телефонов, Android TV и Google TV.

## Скачать

**[Последний релиз и APK](https://github.com/spirevpn/android/releases/latest)**

Требуется Android 8.0 или новее. Один APK поддерживает ARM64, ARMv7, x86 и x86_64, телефоны и TV. После загрузки разрешите установку приложений для браузера или файлового менеджера, через который открываете APK.

## Возможности

- VLESS-подключения на базе Xray.
- Вход по e-mail и коду, загрузка серверов из подписки.
- Автоматический выбор сервера по задержке, ручной выбор и закрепление серверов.
- Настройки маршрутизации, DNS, GeoIP и GeoSite.
- Светлая и тёмная темы; интерфейс Android TV с управлением пультом.
- Kill Switch приложения удерживает защиту при переподключении, пока работает VPN-служба. Защита после остановки приложения требует системной блокировки соединений без VPN, если она доступна на устройстве.

Сверить целостность APK можно по файлу `SHA256SUMS.txt` в релизе.

Репозиторий предназначен только для распространения готовых сборок. Исходный код приложения здесь не публикуется. Автоматические архивы GitHub «Source code» содержат только эту страницу загрузки.

Тестовые debug-сборки используют другую подпись и не обновляются публичным release-APK поверх. Установленная release-версия обновляется следующими релизами с сохранением данных.
